# Terraform

A comprehensive Terraform learning repository covering Infrastructure as Code (IaC), Terraform fundamentals, AWS resource provisioning, state management, modules, interview preparation, troubleshooting, and best practices.

This repository is designed for beginners and aspiring DevOps Engineers who want to learn Terraform from scratch through structured notes and practical examples.

---

# 📚 What is Terraform?

Terraform is an open-source Infrastructure as Code (IaC) tool developed by HashiCorp that enables you to define, provision, and manage infrastructure using code instead of manual configuration.

With Terraform, you can automate cloud infrastructure across multiple providers such as AWS, Azure, Google Cloud, Kubernetes, Docker, GitHub, and many more.
